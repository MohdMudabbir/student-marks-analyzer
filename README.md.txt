*Student Marks Analyzer

## Project Description
Student Marks Analyzer is a Python-based data analysis project built using Pandas.  
It analyzes student performance data from a CSV file and performs data cleaning, analysis, and visualization.

## Features
- Load dataset from CSV file
- Handle and check missing values
- Sort and filter student records
- Identify top scorer
- Pass/Fail classification using lambda function
- Bar chart visualization of marks
- Pie chart visualization of result distribution

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
